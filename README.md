# TagFill — FLAC / MP3 元数据补齐工具

单独把「自动补齐元数据」功能剥离出来的桌面小工具。读取音频文件（FLAC / MP3）已有的标签，
缺什么就自动从 **QQ 音乐** 补什么（专辑、发行日期、封面），然后**原地**写回，不重编码、位级无损。

版本：**1.0.1**

## 功能

- 支持 **FLAC** 和 **MP3**（`-c copy` 不转码，只改标签）。
- 自动补：`歌名(title)` / `歌手(artist)` / `专辑艺术家(album_artist)` / `专辑(album)` / `发行日期(date)` / `封面(cover)`。
- 文件名不强求「歌手 - 歌名」，只要文件名里包含歌手和歌名即可，用 QQ 音乐反查消歧（例如
  `歌名 - 歌手`、`歌手_歌名`、`01 歌手 - 歌名`、`歌手-歌名[FLAC]` 都能识别）。
- 判断不出歌名（文件名和标签里都没有）会直接 **拒绝**，不瞎改。
- 已有标签/封面会被保留，只补齐缺失字段。

## 元数据规则（复刻 flac2am.py）

- 歌名精确匹配 + 歌手匹配，选发行日期最早的专辑。
- 封面：1000×1000 优先，失败退 500×500。
- 来源：QQ 音乐（c.y.qq.com 搜索 + u.y.qq.com 专辑详情）。

## 使用

1. 双击 `TagFill.exe`。
2. 点「选择音频文件」挑 FLAC / MP3（可多选）。
3. 点「开始补齐」。
4. 状态列显示「已补齐」（歌手 · 专辑 · 日期）或「拒绝/失败」及原因。

> 注意：工具**原地修改**所选文件，使用前请先备份。

## 依赖

需要 `ffmpeg.exe` 和 `ffprobe.exe` 与 `TagFill.exe` 放在**同一目录**（发布包里已带）。

## 构建

```powershell
dotnet publish -c Release -r win-x64 --self-contained
```

## 已知限制

- 只补 title / artist / album / album_artist / date / 封面，不写歌词、不写曲目号（曲目号只在文件已有时保留）。
- 只支持 FLAC / MP3；其它格式直接拒绝。
- 需要联网访问 QQ 音乐接口。
